# Chart of accounts templates

Starter charts of accounts for small businesses, one CSV per industry. Each file
uses the same five columns (Number, Name, Type, Detail, Notes) and the same
number ranges, so you can open it in a spreadsheet, delete what you don't need
and import the rest into your accounting software.

| Range | Type |
|---|---|
| 1000s | Assets |
| 2000s | Liabilities |
| 3000s | Equity or net assets |
| 4000s | Income |
| 5000s | Cost of sales |
| 6000s | Operating expenses |

| Folder | Built around |
|---|---|
| `nonprofits/` | Gifts split by donor restriction, expenses split by function for Form 990 Part IX |
| `restaurants/` | Food and beverage sales and cost, delivery apps, tips and sales tax held for others |
| `law-firms/` | The trust account and the client liability it must equal, legal fees by type |
| `contractors/` | Job costs on the lines you bid, retainage, over and under billings |
| `property-management/` | Trust and operating accounts, owner funds and tenant deposits held |

Each folder's README explains the lines that are specific to that industry.
The account names are generic and contain no real company data.
